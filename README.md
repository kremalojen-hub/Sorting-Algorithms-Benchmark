4. Analysis and Discussion (التحليل والمناقشة)
مقارنة التعقيد الزمني (O(N^2) مقابل O(N \log N)):
الخوارزميات البسيطة (Selection, Insertion, Bubble) تأخذ تعقيداً زمنياً بقيمة O(N^2)، مما يجعل أداءها بطيئاً جداً وغير عملي مع البيانات الكبيرة.
خوارزميات التقسيم (Merge و Quick) تعتمد على استراتيجية "فَرِّق تسد" بتعقيد O(N \log N)، مما يقلل عدد العمليات بشكل ملحوظ.
الخوارزمية الأفضل في الحالات المرتبة والجزئية:
Insertion Sort تعتبر الأفضل على الإطلاق في حالة البيانات المرتبة تماماً (Fully Sorted) حيث تهبط تعقيدها إلى الخطية O(N) وتستغرق أزمنة ضئيلة للغاية (~2 ms).
سلوك Quick Sort وتأثير المحور (Pivot):
تعاني خوارزمية Quick Sort في الحالة العكسية أو المرتبة تماماً (إذا تم اختيار المحور بطريقة سيئة كأول أو آخر عنصر) من أسوأ أداء يصل إلى O(N^2) بسبب عدم توازن أجزاء التقسيم.
